# PPM — Sistem Purchasing, Work Order & Keuangan

Seluruh aplikasi ada di folder **[`purchasing/`](purchasing/)**.
Panduan instalasi, migrasi database, hak akses role, dan fitur lengkap: **[`purchasing/README.md`](purchasing/README.md)**.

Singkatnya:
1. Upload isi folder `purchasing/` ke hosting / `htdocs` (XAMPP).
2. Import SQL di `purchasing/database/` sesuai urutan di README.
3. Atur koneksi database di `purchasing/config/database.php`.
